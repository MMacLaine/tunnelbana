# Tunnelbana v0.17 plan: the rewind to 1950

## Purpose

Bring the maclaine.se homepage transition for Tunnelbana ("back to 1950")
into the game itself, so a new player sees the city's metro come apart year
by year down to the first line before the game begins. The owner approved
the homepage version and its pace; this is the same animation, played as the
game's opening instead of as a link transition.

## Release boundaries

- Version `0.17.0`: a new player-facing feature, not a fix.
- No change to `src/sim.js` beyond `VERSION`, and no change to the save
  format. The intro reads no save bytes; it only knows whether the active
  slot had a save when the page loaded.
- No deploy, push, itch build or butler run until the owner asks.

## When it plays

1. First open: the active slot has no save. It covers the boot screen
   (`#boot`) and ends on the real start menu over the real map.
2. New game: Settings, Reset progress (after its confirm click), and
   entering an empty save slot. It ends on the real fresh 1950 board with
   the menu closed, the state an empty slot already lands in today.
3. Never when continuing a save, restoring a backup or importing.
4. Skipped entirely under `prefers-reduced-motion: reduce`.
5. Skipped on first open when `sessionStorage['home-tx']` reads
   `tunnelbana:<ms>` under 30 s old: the player has just watched the
   homepage version. On itch the key is simply absent.
6. Any click, tap or key skips it: a 220 ms fade straight to the end state.
   A key press during the intro is swallowed so it cannot ring the bell.
   A resize also skips it.

Test hooks: `?intro=1` forces it, `?intro=0` disables it, `?intro=manual`
plays it without a clock so a harness can step it frame by frame.

## How it plays (5.6 s, the homepage timeline at 1.75 times)

The homepage beats, minus the frame and caption opening, which only make
sense on the homepage:

1. Today's metro spreads out from T-Centralen in the game's line colours on
   the game's ground, and the year counter comes up on 2026.
2. Rewind: the counter rolls back, each section goes in the year it opened
   (years verified from Swedish Wikipedia's station list, the homepage's own
   table), what has gone stays as a faint dashed plan, colour drains.
3. 1950: Slussen to Hökarängen glows green, the first train runs, the ends
   are named, "1 October 1950" is set in Libre Caslon under the counter.
4. Hand over, live: the overlay's camera eases onto the game's opening
   camera, and the real MapLibre camera is driven to the same place frame by
   frame, so the live map underneath is already exactly where the drawing
   is. The overlay then fades out over the real game, and on first open the
   real menu panel fades in last with a small rise. No captured stills.

If the basemap has not finished loading when the counter reaches 1950, the
clock holds there for up to 1.2 s so the hand over lands on a real map.

## Data and weight

- The SL map's metro geometry, trimmed and baked into `src/intro.js`: seven
  metro lines, simplified to half a pixel at zoom 12 and stored as integer
  offsets, with each stop's distance along its line. No fetch, so it works
  inside the itch zip. `_dev/bake-intro-geo.mjs` regenerates the block.
- Fonts are the game's own vendored files, already declared in index.html.
- Theme: the game's own setting (`tunnelbana_theme`, dark default), passed in
  by main.js. The site theme is never read.
- Weight: about 41 KB for the whole module, about 14 KB gzipped, of which the baked geometry is about 10 KB raw.

## Files

- `src/intro.js` (new): the animation and its baked geometry.
- `src/main.js`: decide when to play, start it at the end of boot and on
  the two new game paths, the debug handle.
- `_dev/build-itch.mjs`, `_dev/deploy-to-site.mjs`: add `src/intro.js` to
  the content hash and import stamping lists.
- `index.html`, `src/sim.js`, `updates.json`: release prep for 0.17.0.
